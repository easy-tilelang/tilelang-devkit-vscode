# Changelog

## 0.1.0

Initial release contents:

- Lower Trace sidebar and viewer for compilation stages, lowering passes, IR, generated code, and logs.
- Previous-stage and pass input/output diffs, repeated pass navigation, and cache reuse details.
- Python script collection with cancellation, partial-record recovery, and bounded collection overhead.
- Portable compilation record import/export and a bundled offline Mock demo.
- Live collection for Linux / Remote SSH with TileLang 0.1.15 at commit `3e923e98`, CPU C target and Cython backend. Other live backends are not yet supported.
- Unit, browser, Extension Host, and real JIT tests; performance benchmarks and CI packaging checks.
